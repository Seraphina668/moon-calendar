# 月记 ☾

一个中文、适合手机使用的私人经期日历。原生 HTML / CSS / JavaScript，无需安装依赖。

## 功能

- 日历浏览、切换月份、返回今天
- 每天记录经期状态、流量、颜色、运动、身体感受、心情、备注
- 经期与运动标记、本月统计
- 修改、删除记录；未保存离开提醒
- JSON 备份与导入（合并记录，同一天以导入内容为准）

## 放到 GitHub Pages

1. 新建 GitHub 仓库，将 `index.html`、`style.css`、`app.js` 和 `.nojekyll` 放在仓库根目录并提交。
2. 进入仓库 **Settings → Pages**。
3. 在 **Build and deployment** 选择 **Deploy from a branch**，选择 `main` 和 `/ (root)`，保存。
4. 发布完成后，打开 Pages 中显示的网站地址。

没有连接 GitHub 账号或指定仓库时，这个交付包不会自动创建仓库或发布网站。

## 数据保存

记录存于当前浏览器、当前网站地址的 localStorage，不上传到 GitHub 或服务器。网站没有第三方资源、分析或网络请求。其他设备和浏览器不会同步，清除网站数据、无痕模式退出或更换网址可能丢失记录，请定期导出。备份文件含个人记录，请自行保管，不要提交到公开仓库。

页面本身没有登录或加密。共用同一浏览器的人可以读取记录。GitHub Pages 的访问权限以仓库及账号配置为准，本页面不会提供访问控制。

本工具仅记录观察，不提供诊断、排卵预测或避孕建议。

## 本地使用

可以直接打开 `index.html` 试用；稳定使用建议部署后固定使用同一个网址。本地文件模式下浏览器的数据保存行为可能不同。
