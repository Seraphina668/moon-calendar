# 月记 ☾

给自己的身体日历。记下经期、运动和每天的感受，慢慢了解自己的节奏。

## 记录一天

1. 在日历中点击想记录的日期，右侧会显示当天的记录表；手机上记录表在日历下方。
2. 选择「非经期」或「经期中」。选择「经期中」后，可以填写流量（点滴、少、中、多）和颜色（粉红、鲜红、暗红、褐色）。
3. 选择当天是否运动，并按需勾选身体与心情标签，支持多选。
4. 在备注里写下睡眠、运动内容或其他想记住的事情。
5. 点击「保存这一天」。未填写的可选项目可以留空。

再次点击已记录的日期，即可查看和修改，修改后需要重新保存。点击「删除」并确认，可以删除该日期的记录。

## 看日历

- 左右箭头：查看上个月或下个月。
- 「今天」：返回今天并打开今天的记录。
- 淡粉色日期背景及粉色圆点：当天标记为经期。
- 绿色圆点：当天有运动。
- 米棕色圆点：当天有保存的记录。
- 顶部统计：当前所查看月份的经期记录天数、运动天数和记录天数。

经期天数是你实际标记为「经期中」的日期数量，页面不会自动补齐未记录的日期。

## 备份与换设备

点击顶部「导出备份」，下载包含已保存记录的 JSON 文件。建议定期备份。

在另一台设备或浏览器中打开月记，点击「导入」并选择之前导出的备份文件。确认后，备份会与现有记录合并：同一天以导入内容为准，其他日期保留。导入前可以先导出当前记录，保留一份副本。

备份只包含已经保存的记录。备份文件含个人记录，请妥善保管，不要上传到公开的 GitHub 仓库。

## 记录保存在什么地方？

记录仅保存在当前浏览器、当前网站地址的本机存储中，不会上传到 GitHub 或服务器，也不会在不同设备间自动同步。页面无需账号，不使用第三方资源或访问统计。

清除浏览器网站数据、退出无痕模式或更换网址可能导致记录无法找回，请使用固定网址并定期导出备份。直接打开本地 HTML 文件时，数据保存行为可能因浏览器而异。

本页面没有登录锁或加密；使用同一浏览器的人可能看到记录。

月记用于记录个人观察，不提供诊断、排卵预测或避孕建议。
