# 月记 ☾

给自己的身体日历，记下经期、运动和每天的感受，慢慢了解自己的节奏。

## 记录今天

1. 点击日历中的日期，日历下方会显示当天的小结。点击「记录这一天」或「编辑这一天」，展开记录表。
2. 选择「非经期」或「经期中」。经期中可以记录流量和颜色。
3. 选择是否运动，按需勾选身体感受和心情，支持多选。填写精力、疼痛、睡眠和近期目标，可以查看当天的运动参考。
4. 在备注中写下睡眠、运动内容，或其他想记住的小事。
5. 点击「保存并查看小结」。表单会收起，并展示已保存的流量、颜色、运动、身体感受和备注。不想填写的可选项目可以留空。

## 查看与修改

- 点击左右箭头切换月份，点击「今天」返回当天。
- 点击已记录的日期，先查看当天小结；需要修改时点击「编辑这一天」，修改后记得保存。
- 在编辑记录时，点击「删除」并确认，可以删除当天的记录。
- 日历中的淡粉色背景表示经期，绿色圆点表示当天有运动，米棕色圆点表示当天有记录。每个日期只显示一行简短文字，开始与结束优先展示，完整流量和颜色请看下方小结。
- 顶部显示当前月份的经期记录天数、运动天数和记录天数。

## 了解自己的周期

在月经开始当天选择「这次开始」，在最后出血当天选择「最后出血日」，然后保存。节点当天会自动选为「经期中」。修改日期时，先取消错误日期的节点，再到正确日期重新标记。

- 周期长度：相邻两次明确标记的开始日期之间的天数。
- 平均周期：最近最多 6 个已记录周期的平均天数。
- 经期长度：一次开始至其后的第一个最后出血日，包含首尾；缺少结束标记时不会推算。
- 下次可能开始：至少有 4 次开始记录后，按最近间隔给出日期范围。数据差异较大或估算范围已过去时，暂不估算。

首页周期概览以今天为截止日期；未来记录暂不参与统计。旧版经期记录仍会保留，但不会自动推断开始与结束，请按实际日期补充节点。漏记一次开始会影响周期长度，请在历史中核对。

估算仅供安排日常生活，不判断排卵，也不能用于避孕。使用激素避孕药、孕期、产后或围绝经期等情况下，不宜依赖日期估算；可在「查看周期历史与估算说明」中关闭估算，继续使用记录和统计。

## 查看运动参考

填写选中日期的精力、疼痛和睡眠后，页面会结合自报状态，提示正常安排原有训练、放轻一点或先照顾不适。未填写的状态不会视为良好；可选减脂或增肌目标，查看对应的一般提醒。

建议会随表单选择更新，点击保存后才会成为当天记录。查看未来日期时，请在当天按实际状态重新确认。

周期第几天只是日期信息，不代表当天的激素水平、训练安全或增肌减脂效果。运动参考不替代个人训练计划或医疗评估；建议依据可在页面中展开查看。

## 备份与换设备

点击「导出备份」，保存已记录的内容。

换设备或浏览器后，打开月记，点击「导入」，选择之前导出的备份文件即可恢复记录。新版支持导入旧版备份，新版导出会同时保留周期节点、身体状态和估算开关。同一天的记录以导入内容为准，其他日期的记录会保留。

记录仅保存在当前浏览器，不会自动同步。清除浏览器数据后可能丢失记录，建议定期备份。
