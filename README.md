# 月记 ☾

给自己的身体日历，记下经期、运动和每天的感受，慢慢了解自己的节奏。

## 记录今天

1. 点击日历中的日期，在记录表中填写当天的情况。手机上的记录表在日历下方。
2. 选择「非经期」或「经期中」。经期中可以记录流量和颜色。
3. 选择是否运动，按需勾选身体感受和心情，支持多选。
4. 在备注中写下睡眠、运动内容，或其他想记住的小事。
5. 点击「保存这一天」。不想填写的可选项目可以留空。

## 查看与修改

- 点击左右箭头切换月份，点击「今天」返回当天。
- 点击已记录的日期，可以查看或修改当天的内容，修改后记得保存。
- 点击「删除」并确认，可以删除当天的记录。
- 日历中的淡粉色背景表示经期，绿色圆点表示当天有运动，米棕色圆点表示当天有记录。
- 顶部显示当前月份的经期记录天数、运动天数和记录天数。

## 备份与换设备

点击「导出备份」，保存已记录的内容。

换设备或浏览器后，打开月记，点击「导入」，选择之前导出的备份文件即可恢复记录。同一天的记录以导入内容为准，其他日期的记录会保留。

记录仅保存在当前浏览器，不会自动同步。清除浏览器数据后可能丢失记录，建议定期备份。
